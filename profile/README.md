# DeskMind 得心

A small computer-use agent that runs on your Mac: a local model decides each step and says how sure it is, asks you when the goal is ambiguous, and asks before anything that sends, deletes, pays or publishes.

| Repository | What it is |
|---|---|
| [brain](https://github.com/deskmind-ai/brain) | The planner: typed step decisions with probabilities, a 0.8B → 4B router, served locally with MLX |
| [eyes](https://github.com/deskmind-ai/eyes) | Screen grounding for apps without an accessibility tree |
| [hands](https://github.com/deskmind-ai/hands) | The macOS desktop harness: observation, actions, approvals, the gym |
| [bench](https://github.com/deskmind-ai/bench) | Sandbox desktop tasks, graders and reference results |
| [app](https://github.com/deskmind-ai/app) | The Mac app (coming later) |

Contributing: see each repository's CONTRIBUTING, the [code of conduct](https://github.com/deskmind-ai/.github/blob/main/CODE_OF_CONDUCT.md) and the [security policy](https://github.com/deskmind-ai/.github/blob/main/SECURITY.md).
